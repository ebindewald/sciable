# gRNAde (inverse RNA design) Runpod Serverless worker dependencies.
#
# Upstream (MIT): https://github.com/chaitjo/geometric-rna-design — the "gRNAde v1.0
# release" (commit 2453b18778a1981ac25f314790e5395f1e9ab218, 2025-12-15). It is not a
# clean PyPI package; worker/Dockerfile.grnade clones it at that commit and the runner
# imports its src.* API directly (featurizer + model), so these are the deps that API
# needs — NOT upstream's full conda env.

# ⚠ torch is NOT pinned here and NOT listed: the image builds on

# build without newer-GPU kernels (the structRFM/RhoFold sm_120-hang trap). torch-2.7
# API-compat with gRNAde's GVP layers is UNVERIFIED — confirm on the first smoke run.
#
# ⚠ The PyG compiled companions (torch_geometric, torch_cluster, torch_scatter,
# torch_sparse) are NOT here — they need wheels matched to the EXACT installed torch
# build, so Dockerfile.grnade installs them with a find-links derived from the running
# torch version. Listing them here would let pip grab a mismatched/CPU wheel.
#
# ⚠ FIRST-BUILD RISK: these are modern py3.11-compatible picks, not upstream's py3.10
# pins. Before the first build, run the checklist B2 import scan at the pinned commit
# over src/ and tools/ and reconcile — gRNAde's featurizer/model/sec_struct_utils pull
